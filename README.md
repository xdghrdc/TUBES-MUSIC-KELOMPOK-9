# TUBES-MUSIC-KELOMPOK-9
Tujuan Kami membuat program ini adalah untuk memenuhi ketentuan Tugas Besar Struktur Data dan juga
bertujuan untuk mengimplementasikan konsep-konsep struktur data dalam sebuah
aplikasi sederhana. Program ini memungkinkan pengguna untuk menambahkan,
memutar, menghentikan, dan mengelola daftar lagu menggunakan struktur data.


## Fitur Program ini
- Menambahkan lagu ke dalam playlist
- Menghapus lagu dari playlist
- Menampilkan daftar lagu
- Memutar lagu
- Menghentikan atau mengganti lagu
- Memutar lagu sebelumnya
- Memutar lagu selanjutnya 

## Struktur Data yang Digunakan
Program ini menggunakan beberapa struktur data, antara lain:
- Multi Linked List untuk menyimpan playlist lagu
- Queue untuk mengatur urutan playlist
- Tree untuk sorting
